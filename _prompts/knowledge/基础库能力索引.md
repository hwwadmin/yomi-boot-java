# 基础库能力索引

---

## 基础库优先使用（强制）

凡涉及 **Java/Spring 基础设施能力**（Web 横切、DB、缓存、锁、限流、消息、鉴权、幂等、事件、对象存储、ID、错误模型、调度等）的设计、实现、改造、巡检或方案评审，**必须优先复用 `yomi-boot-java` 已有模块**。禁止在能力已覆盖且能满足需求时，在业务仓平行实现或重复引入同类第三方库。

### 决策流程

```
阅读本索引
  → 判断是否存在相同或相近能力
    → 有候选：阅读对应 component 源码（AutoConfiguration、Properties、公开 API）
      → 能满足：必须使用该模块（或在其扩展点上扩展）
      → 不能满足：说明缺口后，选择新增方式（见下）
    → 无候选：选择新增方式
```

**无候选 / 需新增时**：须向开发者列出可选方式并确认后，方可编码：**A** 在本仓 `yomi-boot-java-component-*` 扩展；**B** 业务仓临时实现（须说明演进计划）；**C** 经批准的第三方库（须说明为何不扩展 boot）。

### 禁止项（摘要）

- 未读本索引即引入与 component 重复的 Redisson/Kafka/MyBatis 封装等。
- 在业务仓复制 component 内已有逻辑。
- 绕过 `TokenService`、`IdempotencyGuard` 等直接操作底层键空间（除非规范明确允许）。

业务仓与 boot 集成巡检要点见《代码巡检》Skill §3.3；数据/Web/事务契约见 `Java数据访问规范.md`、`JavaWeb与API规范.md`、`Java事务与一致性规范.md`（路径均相对 `_prompts/knowledge/`，与 `skills/` 同为工作流真源）。

## 与业务工程的边界

| 项 | 约定 |
|----|------|
| boot 仓 | 仅 `yomi-boot-java-base/core/component-*` 与 `qucik-starter` 演示；**禁止**产品领域表与业务规则 |
| 业务仓 | 产品代码与 DDL；可选用任意分层命名，须在 spec「本项目结构约定」写明 |
| 集成 | 依赖 `core` + 按需 `component-*`；选型见下文与 [组件使用说明](../../docs/组件使用说明.md) |

## 1. 基础与核心

| 模块 | 职责 |
|------|------|
| `yomi-boot-java-base` | `Response`、`BizException`、`PageRequest`、`JsonUtils`、`IRepository` 等 |

## 2. 组件（component-*）

| 模块 | 配置前缀（示例） | 职责 |
|------|------------------|------|
| `component-ds` | `spring.datasource.*`、`yomi.ds.*` | 主库四件套（全 `@Primary`，**独占装配**：业务只配 yml、不得声明 `masterXxx`）、MyBatis-Plus、`MyBatisDao`；附加库由业务自建（自己的 Bean 名、不标 `@Primary`） |
| `component-redis` | `spring.data.redis.*`、`yomi.ratelimit` | Redis、锁、限流、`ClusterTask` 集群定时任务 |
| `component-kafka` | `spring.kafka.*` | Kafka 发送 |
| `component-token` | `yomi.token` | 会话令牌 |
| `component-rbac` | `yomi.rbac` | 权限拦截 |
| `component-idempotency` | `yomi.idempotency` | 业务幂等 |
| `component-event` | `yomi.event` | 事件/outbox |
| `component-oss` | `yomi.oss` | 对象存储 |
| `component-captcha` | `yomi.captcha` | 图形验证码（读图输入/看图算数；组件不提供接口） |
| `component-desensitize` | 无（自动装配） | 脱敏：`DesensitizeService.mask(策略名, 值)` + 策略中心（12 内置策略，宿主同名策略覆盖内置） |

**本栈未提供**：DTM/Saga、Consul 服务发现；跨边界一致性见 [Java事务与一致性规范](./Java事务与一致性规范.md) §5。
