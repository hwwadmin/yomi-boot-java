# 显化分层与用例代码示例

> 写 spec 第八章–第十章、第十四章前 Read 本文。模块与包路径以 spec §2.3 为准。

## 3.3 领域模型代码示例

**业务 Model**（模块 `config-domain-api`，包路径以 spec §2.3 为准）

```java
@Data
public class ConfigModel {
    private Long id;
    private String configKey;
    private String configValue;
    private String description;
}
```

**领域服务接口**（模块 `config-domain-api`）

```java
public interface ConfigDomainService {
    ConfigModel create(ConfigModel draft);
    ConfigModel getById(Long id);
    Page<ConfigModel> page(ConfigQuery query, Pageable pageable);
}
```

**领域服务实现**（模块 `config-domain`）

```java
@Service
@RequiredArgsConstructor
public class ConfigDomainServiceImpl implements ConfigDomainService {
    private final ConfigDomainRepository configDomainRepository;

    @Override
    public ConfigModel create(ConfigModel draft) {
        // 唯一性等领域不变量；再 configDomainRepository.save(draft)
    }
    // ...
}
```

**仓储端口**（模块 `config-domain-api`）

```java
public interface ConfigDomainRepository {
    ConfigModel save(ConfigModel model);
    Optional<ConfigModel> findById(Long id);
    Page<ConfigModel> page(ConfigQuery query, Pageable pageable);
}
```

**表 Entity**（模块 `config-infrastructure`，含 `ConfigMapper`）

```java
@TableName("t_config")
@Data
public class ConfigEntity extends BaseEntity {
    private String configKey;
    private String configValue;
    private String description;
}
```

> `ConfigDomainRepositoryImpl` 仅在 **`config-infrastructure`** 模块；usecase 模块通过 domain-api 依赖，**不**直接依赖 infrastructure。

**缓存等非 DB 端口**（模块 `config-domain-api`，由 infrastructure 实现）

```java
public interface ConfigCachePort {
    void rebuild();
}
```

**单上下文数据流**：

```text
UseCase → DomainService → DomainServiceImpl → DomainRepository → DomainRepositoryImpl → DB
```


## 3.4.1 UseCase / Helper 代码示例

**结构说明**（模块 **`{product}-usecase`**，包路径以 spec §2.3 为准；**仅**依赖各 `{context}-domain-api` 与 web 侧 `*Request`/`*Response`，**不**依赖 infrastructure）：

**入参 / 出参 DTO**（可与 `adapter-web` 同模块或独立 api 契约模块）

```java
@Data
public class GetConfigDetailRequest {
    @NotNull
    private Long id;
}

@Data
public class GetConfigDetailResponse {
    private Long id;
    private String configKey;
    private String configValue;
}
```

**单域读用例**（`GetConfigDetailUseCase.java`）

```java
@Service
@RequiredArgsConstructor
public class GetConfigDetailUseCase {
    private final ConfigDomainService configDomainService;
    private final ConfigHelper configHelper;

    public GetConfigDetailResponse execute(@Valid GetConfigDetailRequest req) {
        ConfigModel model = configDomainService.getById(req.getId());
        return configHelper.toDetailResponse(model);
    }
}
```

**单域分页读用例**（`PageConfigUseCase.java`）

```java
@Service
@RequiredArgsConstructor
public class PageConfigUseCase {
    private final ConfigDomainService configDomainService;
    private final ConfigHelper configHelper;

    public PageResponse<ConfigResponse> execute(@Valid PageConfigRequest req) {
        Page<ConfigModel> page = configDomainService.page(
                configHelper.toQuery(req), configHelper.toPageable(req));
        return configHelper.toPageResponse(page);
    }
}
```

**单域写用例**（`CreateConfigUseCase.java`；业务写事务默认在 `execute`）

```java
@Service
@RequiredArgsConstructor
public class CreateConfigUseCase {
    private final ConfigDomainService configDomainService;
    private final ConfigHelper configHelper;

    @Idempotent(key = "#req.idempotencyKey", namespace = "config:create")
    @Transactional(rollbackFor = Exception.class)
    public CreateConfigResponse execute(@Valid CreateConfigRequest req) {
        ConfigModel draft = configHelper.toModel(req);
        ConfigModel saved = configDomainService.create(draft);
        return configHelper.toCreateResponse(saved);
    }
}
```

**跨上下文读用例**（`GetProfileUseCase.java`）

```java
@Service
@RequiredArgsConstructor
public class GetProfileUseCase {
    private final SubjectDomainService subjectDomainService;
    private final RoleDomainService roleDomainService;

    public GetProfileResponse execute(@Valid GetProfileRequest req) {
        SubjectModel subject = subjectDomainService.getById(req.getSubjectId());
        List<RoleModel> roles = roleDomainService.listBySubject(req.getSubjectId());
        return GetProfileResponse.of(subject, roles);
    }
}
```

**无请求体用例**（`RefreshConfigCacheUseCase.java`；经 `ConfigCachePort`）

```java
@Service
@RequiredArgsConstructor
public class RefreshConfigCacheUseCase {
    private final ConfigCachePort configCachePort;

    public void execute() {
        configCachePort.rebuild();
    }
}
```

**第十章必填（写用例）**：`@Idempotent`、`@Transactional` 落点（**默认** `*UseCase#execute`；领域内按需写 `*DomainServiceImpl` 方法）。


## 3.7 Controller 示例

**Controller 注册示例**（`ConfigController.java`）：

```java
@RestController
@RequestMapping("/v1/config")
@RequiredArgsConstructor
public class ConfigController {
    private final PageConfigUseCase pageConfigUseCase;
    private final GetConfigDetailUseCase getConfigDetailUseCase;
    private final RefreshConfigCacheUseCase refreshConfigCacheUseCase;

    @PostMapping("/query")
    public Response<PageResponse<ConfigResponse>> page(@Valid @RequestBody PageConfigRequest req) {
        return Response.success(pageConfigUseCase.execute(req));
    }

    @PostMapping("/detail")
    public Response<GetConfigDetailResponse> detail(@Valid @RequestBody GetConfigDetailRequest req) {
        return Response.success(getConfigDetailUseCase.execute(req));
    }

    @PostMapping("/cache/refresh")
    public Response<Void> refreshCache() {
        refreshConfigCacheUseCase.execute();
        return Response.success();
    }
}
```
